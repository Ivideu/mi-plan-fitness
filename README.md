# 🚀 Plan de Transformación 4 Semanas - 44 años / 90kg
**Objetivo:** Vientre plano, definición de tren superior y protección de rodillas.
**Condición:** Diabetes Tipo 2 (Control Glucémico Estricto).

## 📅 Rutina Diaria (06:00 - 07:00 AM)
| Bloque | Ejercicio | Series/Reps | Notas de Salud |
| :--- | :--- | :--- | :--- |
| **Calentamiento** | Movilidad articular | 5 min | Foco en hombros y rodillas. |
| **Pecho** | Press en máquina | 4 x 12 | Evita bloqueos bruscos. |
| **Espalda** | Jalón al pecho | 4 x 10 | Espalda recta, core activo. |
| **Bíceps** | Curl con mancuerna | 3 x 12 | Controla el descenso. |
| **Pierna/Rodilla** | Extensión de cuadriceps | 3 x 15 | Carga baja, muchas reps para lubricar.[cite: 4] |
| **Core/Vientre** | Plancha Isométrica | 4 x 45s | Protege la espalda lumbar.[cite: 4] |
| **HIIT Final** | Elíptica (Sin impacto) | 15 min | Intervalos 1:1.[cite: 4] |

## 🥗 Nutrición Mercadona (Bajo Índice Glucémico)
- **Desayuno:** Café con leche (semidesnatada o +Proteína) + Tostada Centeno con Pavo.[cite: 4]
- **Comida:** 200g Pollo/Conejo + Brócoli/Judías + 40g Arroz integral.[cite: 4]
- **Cena:** Pescado blanco/Salmón + Ensalada verde + 1/2 Aguacate.[cite: 4]
